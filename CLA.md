## How to sign

Post this comment on your pull request, exactly as written:

```
I have read the CLA Document and I hereby sign the CLA
```

Posting that comment means you accept this Agreement. The CLA bot records your
GitHub username, your GitHub user ID, the comment, the pull request, and the time.
You only sign once, and the signature covers all of your Contributions to the
Project, including any you made before signing.
