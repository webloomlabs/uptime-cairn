# CLA signatures

Signatures for the [Uptime Cairn Contributor License Agreement](https://github.com/webloomlabs/uptime-cairn/blob/main/CLA.md),
written by the CLA workflow (`.github/workflows/cla.yml` on `main`) when a
contributor signs on a pull request.

- `signatures/version1/cla.json` holds signatures for CLA version 1.0.
- Do not protect this branch: the workflow commits to it.
- Do not edit or delete signatures by hand. Each entry is the record of an
  agreement. If the CLA text changes materially, start a new `version2` file
  rather than rewriting this one.
